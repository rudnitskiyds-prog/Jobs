# Финстарт Москва

Агрегатор стажировок и вакансий без опыта в экономике и финансах в Москве, с упором на банки и инвестиции.
Каждый день собирает предложения из каталогов для студентов, Telegram-каналов и пабликов VK, отбирает те,
куда берут студентов старших курсов и выпускников, и публикует их на сайте (GitHub Pages).

В карточке вакансии есть работодатель, зарплата, условия (формат, график, занятость, опыт), должность
и подразделение, источник, дата публикации и ссылка на отклик.

## Источники

| Источник | Как собирается | Нужен ключ |
|---|---|---|
| **Changellenge >>** (changellenge.com/vacancy) | каталог «Стажировки в Москве» + «Москва, нет опыта», страница каждой вакансии | нет |
| **Future Today** (fut.ru/internship) | каталог стажировок и программ для студентов | нет |
| **Telegram** | веб-превью `t.me/s/<канал>`: Changellenge, БУДУ, careerspace, центры карьеры Финуниверситета, ВШЭ, МГИМО, РЭУ, РАНХиГС, карьерные каналы ВТБ, Альфа-Банка, Газпромбанка, РСХБ, Банка России, Мосбиржи, Т-Банка, «Яков и Партнёры» и др. Подборки разбиваются на отдельные вакансии | нет |
| **«Работа России»** (trudvsem.ru) | открытое API, регион Москва | нет |
| **hh.ru** | официальное API: Москва, «нет опыта», профроли «Финансы», «Стратегия, инвестиции, консалтинг», «Страхование» + поиск «стажер/intern/младший аналитик» | `HH_TOKEN` |
| **VK** | API `wall.get` по пабликам (Changellenge, fut.ru, БУДУ, центры карьеры, банки) | `VK_TOKEN` |

Список каналов, пабликов, ключевых слов и известных работодателей лежит в [`scraper/config.py`](scraper/config.py).
Чтобы добавить канал, допишите строку в `TELEGRAM_CHANNELS` или `VK_GROUPS`.

### Как отбираются вакансии

1. **Финансы и экономика**: ключевые слова (банк, инвестиции, аудит, налоги, M&A, риски, казначейство, МСФО…) или известный финансовый работодатель.
2. **Без опыта**: стажёр, intern, младший, junior, студент, выпускник, «без опыта». Позиции «ведущий», «руководитель», «опыт от 3 лет» отсекаются.
3. **Москва**: упомянута Москва или удалёнка; вакансии только в других городах отбрасываются.
4. **Не IT и не продажи**: разработчики, ML, HR, маркетинг, курьеры и т. п. исключены.
5. Посты-мероприятия, статьи и анонсы (дни открытых дверей, вебинары, форумы) не попадают в ленту.
6. Дубли из разных источников склеиваются, в карточке указано «также: …».

Банки и инвестиции помечены синим бейджем, по ним есть отдельный фильтр и сортировка «банки и инвестиции выше».

## Как оставаться в курсе

- **Сайт** обновляется дважды в день (07:17 и 17:43 МСК). Новые за последние 48 часов отмечены бейджем «Новое».
- **RSS**: `feed.xml` на сайте, можно подписаться в любом RSS-ридере или через Telegram-бот для RSS.
- **Telegram-бот** (опционально): после каждого обновления присылает список новых вакансий, банки и инвестиции идут первыми.
- На сайте можно добавлять вакансии в избранное и скрывать неинтересные; это хранится в вашем браузере.

## Запуск

### 1. GitHub Pages и ежедневное обновление

1. Слейте ветку в `main`: расписание GitHub Actions работает только в ветке по умолчанию.
2. **Settings → Pages → Build and deployment → Source: GitHub Actions.**
3. **Actions → «Обновление вакансий» → Run workflow**, чтобы запустить первый сбор вручную.
4. Сайт появится по адресу `https://<ваш-логин>.github.io/<репозиторий>/`.

### 2. Секреты (Settings → Secrets and variables → Actions)

Все секреты необязательны: без них соответствующий источник пропускается.

| Секрет | Где взять |
|---|---|
| `HH_TOKEN` | [dev.hh.ru](https://dev.hh.ru) → зарегистрировать приложение → токен приложения (client credentials). Без него API hh.ru отвечает 403. |
| `VK_TOKEN` | [dev.vk.com](https://dev.vk.com) → «Мои приложения» → создать приложение → «Сервисный ключ доступа». |
| `TELEGRAM_BOT_TOKEN` | создать бота у [@BotFather](https://t.me/BotFather), отправить боту любое сообщение. |
| `TELEGRAM_CHAT_ID` | ваш числовой id, например от [@userinfobot](https://t.me/userinfobot). |

### 3. Локально

```bash
pip install -r requirements.txt
python -m scraper.main --no-notify            # все источники
python -m scraper.main --only telegram futru  # выборочно
python -m http.server -d site 8000            # сайт на http://localhost:8000
python -m unittest discover tests             # тесты разбора
```

## Ограничения

- Сайты банков (Сбер, ВТБ, Альфа, Т-Банк, Газпромбанк) отдают вакансии через закрытые JS-API, часть из них
  недоступна из-за рубежа, где работают серверы GitHub. Их вакансии попадают в агрегатор через карьерные
  Telegram-каналы банков, каталоги Changellenge и fut.ru и через hh.ru (с токеном).
- В Telegram-постах зарплату и подразделение часто не пишут. Если поля нет в источнике, в карточке будет «не указана».
- Если какой-то источник блокирует запросы с серверов GitHub, можно запускать сбор на своём компьютере
  (`python -m scraper.main`) и пушить `site/data/vacancies.json`, или подключить self-hosted runner.
